In my React Native (Expo) app, I need to completely redesign the main Home/Browse screen to be highly vibrant, fun, and tactile. Break away from standard white cards and use a colorful, block-based 'bento box' UI that aligns with a soft, Studio Ghibli/Ponyo aesthetic.

1. Screen Setup & Header:

Set the main screen background to a warm cream (#FBFBF9).

At the top left, add a large, bold greeting: 'HEY, [UserInitial]' (fontSize: 32, fontWeight: '900', color: '#2C555C' primary dark teal).

2. The 'Pebble' Quick Filters (Top Row):

Replace the standard white filter buttons with a horizontal ScrollView of 'pebbles'.

Each filter chip should have a unique, solid pastel background (e.g., peach #FADCB3, mint #A8DADC, lavender #DDBDF1, ice blue #A2D2FF).

Inside the chip, stack a small icon on top of the text. borderRadius: 20, paddingVertical: 12, paddingHorizontal: 16. Text should be dark teal (#2C555C).

3. Browse By Housing Type (The Block Grid):

Below the filters, create a row of square, blocky cards for the main categories (Semester & Year, Summer, Short-Term).

Each block should have a solid pastel background matching the Ponyo color palette.

Layout: borderRadius: 16. Center the content. Put a large, colorful icon near the top, and the category name in bold dark teal text at the bottom.

4. The 'Fun' Features (Matchmaker & Crash & Cash):

These two features must look completely different from the rest of the app—massive, urgent, and highly clickable.

Year-Long Matchmaker Card: Make this a massive, full-width block (width: '100%', height: 140, borderRadius: 24).

Background: A deep, rich coral/terracotta (#E06D53).

Typography: Make the title absolutely massive and bold (fontSize: 28, fontWeight: '900', dark red/brown text).

Add a large, stylized Heart/Location icon on the left side.

Crash & Cash Card: Make this another massive, full-width block below the Matchmaker.

Background: A warm, vibrant orange/peach (#FFB48A).

Typography: Use a slightly blockier or edgier font weight for the title to show urgency.

Highlight Effect: For the subtitle text ('...paid in cash, boba, or Lion cover'), wrap the words 'boba' and 'Lion cover' in their own little colored background pills (e.g., a hot pink background for boba, a bright yellow for Lion cover) so they look like they were highlighted with a marker.

Add a large Couch and Lightning Bolt icon on the left side.

5. Global Styling Constraints:

Remove all thin, harsh grey or black borders from the entire screen.

Use soft, tinted drop shadows (e.g., a dark orange shadow for the Crash & Cash card, a dark teal shadow for the category blocks) to make them look like physical, 3D buttons you can press.
